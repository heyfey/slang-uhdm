-------------------------

array state § satArrArgFirstElem5 reads is the state AT THE ESCAPE.  Surelog's
evaluator does NOT stop there: it runs the body to completion on garbage and
returns whatever the returned array holds AT THE `return`.  Three cells are
PRISTINE-RIGHT -> PATCHED-WRONG because of it (12 dump objects).

THE FIX (this verifier's, in `wbReturnedArraySym`)
-------------------------------------------------
Claim only the shape where nothing after the escape can still change the
returned array — Rggen's `get_sub_n_list`:
  (1) exactly ONE tracked packed-array local (element width > 1);
  (2) at least one `return`, and EVERY return names that array;
  (3) exactly ONE whole-array assignment, non-compound, lexically BEFORE every
      element write;
  (4) every element write selects through a BARE VARIABLE, all naming the SAME
      variable.
v3/v4/v6 fail (1); v7 fails (4); v8 fails (3).  Rggen passes all four.

RANKED RESIDUES THIS VERIFICATION ADDS TO THE IMPLEMENTER'S FIVE
---------------------------------------------------------------
6. THE ESCAPE-TIME STATE IS NOT THE RETURN-TIME STATE.  `v4_single`/`v7_post`
   prove Surelog runs the body to completion past the runaway index.  Modelling
   that needs Surelog's OUT-OF-RANGE READ semantics: in the Rggen body the read
   `current_n -= list[list_index]` out of range must yield something that
   TERMINATES the `while (current_n > 0)` loop (returning 0 would spin forever,
   and golden terminates).  Decode that one value and the gate can be dropped
   and residues 2 and 3 come into range at the same time.
7. x1_argshapes' `get_next_n(COPY)` — golden corrupts a packed-array localparam
   that merely COPIES the escaping one; we keep slang's fold.  A one-hop
   propagation of the claim through `localparam A = B;`.
8. The nested actual `get_next_n(id(SUB_N_LIST))`: golden FOLDS the inner
   pass-through call to a constant, we keep the `func_call`.  Pre-existing in
   base and orthogonal to this law.
