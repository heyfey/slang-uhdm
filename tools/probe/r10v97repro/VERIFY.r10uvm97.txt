        span reverts from the base's 10:13-10:20 to its own 15:13-15:20)

   MECHANISM.  The drain's group is keyed on the TARGET class; a member is a
   (declaring class, typedef name) pair.  The shipped gate dedups members on
   (generic declaring class, name) and DROPS every duplicate before the alias
   loop.  When the duplicated declaration is NOT the group's base — a real
   cross-class group whose clone member is a parameterized class with N live
   specializations — golden still has ONE object for that declaration and it IS
   aliased, while we have N copies and nothing says which of them the class's
   vpiTypedef LISTING and its use sites read.  In c1 the copy that survived the
   dedup is the UNREACHABLE one and the LISTED one lost its alias.

2. THE FIX (minimal, in the same block)
   § classNestedTdDupCopiesFollowTheirDeclaration97v.  The duplicate identity
   now decides only (a) the group's real member count and (b) whether a member
   is a copy of the BASE's own declaration:
     * count DISTINCT (declKey, name) pairs; < 2  => the group is one
       declaration wearing N specializations, skip it entirely (this is the
       pass's head fix, unchanged);
     * inside the alias loop skip only the members that share the BASE's
       (declKey, name) — golden has one object there and it carries no alias;
     * every copy of every OTHER declaration is aliased exactly as pass 54 did.
   Diff: 6 lines of code (one std::set, one size test, one skip) + comment.
