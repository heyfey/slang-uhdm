THE LAW THIS PASS TRANSCRIBES IS STEP (3), AND ITS FENCE IS STEP (2):
  * (3) the home package's DEF listing of an out-of-body class method binds a

        parameter of that name — then the DESIGN-LEVEL PARAMETER OBJECT wins,
        because the walk runs BEFORE step (3).

holds the very object our own DEF `param_assign` carries — `ct214bind --parhs`
