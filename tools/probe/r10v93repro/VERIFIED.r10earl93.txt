R10 THE WRAPPED VALUE DOES NOT PROPAGATE.  New measurement (v5): with
    `localparam A = 64'(64'd5)`, golden gives `D = 96'(A)` -> UINT:0 and
    `C = A + 1` -> INT:1 because A itself is already wrapped to 0 in golden's
    value store; ours gives 5 and 6, before AND after.  A bare read `B = A`
    DOES land on golden, but only because the emitter substitutes a CLONE of
    A's initializer, which re-folds through the gated mint.  Any read of a
    wrapped parameter inside a larger expression stays unwrapped.  This is the
    deepest limit of a mint-site model: the law rewrites digits, it does not
    rewrite slang's constant value.
