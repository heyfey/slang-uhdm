r10earl100 -- THE LISTING CENSUS (MEASUREMENT ONLY; uhdm-cmp is the judge).

WHAT IS KEYED.  ct100cen.cpp emits, for every scope that carries a
Variables / Nets / Array_nets listing in either database, one line per signal:

    SIG <view>|<homekind>|<homefullname>|<signame>   <list>:<kind>
    CNT <view>|<homekind>|<homefullname>             nV=<n> nN=<n> nA=<n>

<view> is D (design::AllModules/AllPackages/AllInterfaces -- the definition
listing) or E (design::TopModules -- the elaborated tree); the two producers
name the two views identically, so the view MUST be in the key.  The key
carries NO SPAN and NO typespec: this census scores exactly the two things the
judge reads here -- WHICH LISTING a signal sits in and WHAT KIND it is -- plus
the vector SIZES, which are what BaseClass.h's vector SafeCompare actually
reports (it returns on a size mismatch with BOTH owners set, before comparing
a single element).  cen100.py joins the two sides as MULTISETS (collections.
Counter), never a last-writer dict: a name can legitimately repeat in a listing.

CALIBRATION.  The scorer reads ZERO one-sided cells and ZERO count mismatches
on all 1358 uhdm2rtlil databases (23620 scopes, 31664 cells) -- every one of
which uhdm-cmp calls CMP_EQUAL.  0 false positives on 1358 equal databases.
