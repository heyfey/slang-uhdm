THE LAW
  § pkgVarBindsOnlyThroughInstance88 — a `ref_obj` carries an `Actual_group`
  pointing at a PACKAGE-SCOPE variable ONLY when the ENCLOSING subroutine
  carries that package as its `vpiInstance`.  Surelog binds a late-bound
  reference to a package's `Variables()` listing in exactly one place,
  `UhdmWriter::lateBinding`, and reaches it only through `func->Instance()`
  under the guard `inst->UhdmType() == uhdmpackage`.  A class method WRITTEN
  INSIDE THE CLASS BODY has NO `vpiInstance` at all, so that listing is
  unreachable from it and golden leaves the reference BARE.

THE PREDICTOR (pred88.sh, run on the PRISTINE workdir)
  Every `ref_obj` whose `Actual_group` is a package-scope variable AND whose
  enclosing task_func prints `SITEINST=<null>` while sitting under a
  `class_defn` (`SITECLS=1`) is a cell this law REMOVES.  Both facts are read
  off the pristine database by ct88cen; no patched binary is involved.
