r10earl76 — GRID SCORE (score76.py, order-free MULTISET distance; the pass's own
grids plus the two earlier passes' grids the law reaches).  Golden = LHS always.

ALL-FIELDS = every payload token scored, including the enum_const's VpiValue.
JUDGED     = the same with `actval=` dropped, because enum_const::Compare reads
             VpiType / VpiName / VpiDefName / VpiDecompile / VpiSize and NEVER
             VpiValue.  BOTH numbers are reported; the difference is exactly the
             INT:/UINT: prefix residue named in the README.
