## 2. THE DEFECT THE VERIFICATION FOUND — § `pkgTypeParamLocalIsNotATypedef202v`

**A `parameter type` IS NOT A TYPEDEF, and golden does not degrade it.**

slang models every type parameter as a same-named `TypeAliasType` living in the
parameter's OWN scope (`TypeParameterSymbol`'s constructor). So a PACKAGE-scope

```systemverilog
parameter type tparV5202 = PlainV5202;
```

satisfies **all three** of `pkgClassTdLocalName202`'s clauses — `TypeAlias`,
canonical `ClassType`, parent scope `Package` — and a local declared with it
inside a wildcard-import clone body was degraded by the pass as shipped.
§ 198 is protected from the CLASS-scope twin of this only because
§ `oobClassTypeParamLocalUnsupported105` sits ahead of it in the chain; the
PACKAGE-scope one has no earlier owner.

**MEASURED**, arm `arms202v/v202_5_typeparam.sv`, one real Surelog golden with
**ZERO Surelog errors**, both views, both sites, the law's own typedef cell
declared and used beside it in the same cloned body:

| cell | golden | pristine | patched (02bc6ff4) |
|---|---|---|---|
| `tparV5202 tfTparV5` (type parameter) | `class_typespec` **`PlainV5202`** `@quarryV5202` | `class_typespec` UNNAMED, no instance | **`unsupported_typespec` `tparV5202`** `@quarryV5202` |
| `clsTdV5202 tfTdV5` (the law's typedef) | `unsupported_typespec clsTdV5202 @quarryV5202` | `class_typespec quarryV5202::clsTdV5202 @sluiceV5202` | `unsupported_typespec clsTdV5202 @quarryV5202` — correct |

Golden **RESOLVES** the type-parameter cell, to a `class_typespec` named after
the TARGET class and instanced at the home package, in the clone exactly as in
the home. The pristine binary already gets that cell's NAME and INSTANCE wrong,
but it gets the **KIND** right — and `typespec::Compare` reads `VpiType`
**first**. Firing there turns a wrong-name/right-kind cell into a WRONG-KIND
one: **MOVED-WRONG 3 in def and 3 in elab**, on both this arm and
`arms202v/v202_1_chains.sv`.

**THE FIX**, `src/EmitHelpers.h`, one clause, inside `pkgClassTdLocalName202`
and before its package-scope test, using the header's own existing helper:

```cpp
if (typeParamOfAlias(ty.as<slang::ast::TypeAliasType>()))
    return {};
```

With it the arm reads **TO-GOLDEN 3 / AWAY-GOLDEN 0 / MOVED-WRONG 0** in both
views, the typedef cells beside it still firing, and every one of the pass's
own five grid arms scores **exactly** what it scored before, arms A and E
CMP_EQUAL in both views included.

**The fix costs the corpus nothing.** Byteverify between the implementer's
binary and the verified one: **0 / 1358** uhdm2rtlil and **1 / 956** surelog,
the one being Scoreboard/default — the documented coin, whose ORDER-BLIND
diff between the two is two uhdm-dump path-banner lines and **zero** content
lines. The four law rows' databases are byte-identical between the two
binaries.

## 4. RESIDUES, RANKED

1. **The type parameter's own NAME and INSTANCE.** Golden reads
   `class_typespec PlainV5202 @quarryV5202`; we read an UNNAMED
   `class_typespec` with no instance, in the clone AND in the home. The fence
   above leaves that exactly where the pristine binary had it — a
   name-and-instance law for a `parameter type`-typed local, and it is
   judge-visible on both fields. `arms202v/v202_5_typeparam.sv` is its arm.
2. **The FORMAL** (§ 36's `io_decl` site) — golden degrades a clone's formal
   typed by a package-scope class typedef and we resolve it; 3 keys per view in
   `v202_3_formals`. This is r10uvm202's own R2.
3. **The FREE-SUBROUTINE clone** — r10uvm202's R3, correctly declined by the
   `pkgClassTfClone` conjunct because that driver shares one typespec between
   the home and package listings; the decline is what buys AWAY-GOLDEN 0.
4. **The name collision across packages** — in `v202_2_samename`, golden names
   `betaV2202`'s own HOME cell `alphaV2202::dupTdV2202` when both packages
   declare a typedef of that name; we name it `betaV2202::dupTdV2202`. A
   Surelog naming quirk, unmoved on all three binaries, orthogonal to this law.
5. **The SCOPED spelling, the ARRAY fence, the clone's plain-typedef instance
   stamp, listing arity** — r10uvm202's R1 / R4 / R5 / R6, all re-measured
   unmoved on the verified binary.
