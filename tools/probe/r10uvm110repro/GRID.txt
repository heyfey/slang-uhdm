r10uvm110 GRID -- the four arms scored THREE WAYS (golden / pristine / shipped) in
BOTH views by score110.sh.  TO_GOLDEN = pristine wrong, shipped right; AWAY = a
REGRESSION; LATERAL = both wrong, differently; STILL = both wrong, identically.
Keys are per named ancestor over a MULTISET of projected rows, so a single key
carries every assignment in that subroutine -- the arms are NOT one-cell-per-key.

The grid deliberately varies naming style, casing, identifier length, numbers and
ORDER between arms (a1 lower/mixed, a2 UPPER+digits, a3 mixed, a4 different again)
so that no cell can agree by an accident of a uniform scheme.
