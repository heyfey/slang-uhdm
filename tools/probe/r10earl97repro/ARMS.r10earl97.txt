g0_head97  THE HEAD IN MINIATURE, and the positive control.  A typed module-body
   localparam with a COMPUTED default (`localparam int PtrW = $clog2(Width+1)`)
   used as a bare `PtrW'(m)` cast width in an instantiated submodule -- the
   source shape of prim_packer.sv:31.  ONE head before, uhdm-cmp EQUAL after,
   in BOTH views.

g1_kind97  THE KIND AXIS.  int / int unsigned / integer / integer unsigned /
   shortint / longint / byte / time / bit [7:0] / logic signed [7:0], each a
   COMPUTED-default localparam used as a bare cast width.
     * `int`            golden sgn=1, ours 0 -> 1.   THE LAW'S ONLY CELL HERE.
     * `int unsigned`   golden sgn=0, ours 0.  AGREES BEFORE AND AFTER -- the
                        AWAY control: the law copies the DECLARATION's flag,
                        so an unsigned target stays unsigned.
     * every other kind: golden REUSES the declaration typespec (integer /
                        shortint / longint / byte / time / bit / logic) at the
                        cast site and we mint a NAMED `int` typespec at the
                        identifier span instead -- 8 GOLDEN-ONLY + 16 OURS-ONLY
                        rows, IDENTICAL before and after.  That is R1, a
                        different law with its own population; this law is
                        gated on `int_typespec` and cannot reach it.

g2_owner97  THE OWNER AXIS.  A port-list parameter, a body localparam, a
   localparam whose value depends on an INSTANCE OVERRIDE, a package parameter,
   a type-parameter-derived width, plus the non-cast owners the payload also
   lives on (typedef, function return, struct member, variable, port), over TWO
   instances of one definition.  FOUR law cells move (P_BODY and P_OVR in
   u_s and u_s2) -- the override-dependent one included.  The 3 that stay are
   pre-existing: two imported package-parameter rows we do not list under the
   module (R3) and one unparented typedef row.

g3_home97  THE HOME AXIS.  package / module / submodule / gen scope /
   interface / THREE INSTANCES OF ONE DEFINITION.  All THREE instances of
   sub3h97 move together (29:14, one cell each); the elab view becomes uhdm-cmp

g4_form97  THE FORM AXIS -- the distinguishers the arm is gated on.
     W_LIT   literal default, bare cast   : both sides mint the NAMED
