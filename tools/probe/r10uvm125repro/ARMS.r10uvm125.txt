r10uvm125 — THE GRID.  Four arms, each built with SURELOG (golden) and with the
frozen PRISTINE and PATCHED binaries in BOTH views, censused with cen125 and
scored with score125.py.  LHS IS ALWAYS GOLDEN.

  arm125.sh builds one arm; score125.py joins the two censuses as multisets.

== the grid axes ==
  g125_a_dirs.sv    DIRECTIONS x conversion:  output/SAME type (control),
                    output/narrower, output/int, output inside a COMPOUND
                    statement (`ok &= f(...)` — the corpus shape), inout/
                    converting, ref/same, TASK call/converting, and a bare
                    `void'(f(...))` statement call.
  g125_b_shapes.sv  ARG SHAPES for a converting output/inout formal: bare ref,
                    same-type control, bit-select, part-select, indexed
                    part-select, struct member, array element, `this.`-qualified
                    property, inout converting, inout same-type control, a
                    WIDENING actual (the other conversion direction), a local
                    same-type control and a local converting.
  g125_c_kinds.sv   CALL KINDS: DPI import function, DPI import task, package
                    free function, package task, class method (method_func_call),
                    class method task (method_task_call), $value$plusargs and
                    $sscanf (system functions with an output formal).
  g125_d_homes.sv   HOMES x INSTANCES: the same converting output actual inside a
                    module task, a module function, an initial block, an always
                    block and a generate block, in THREE differently
                    parameterised instances of the same module.

== what an arm agreeing does NOT prove ==

  `fsame` / `fio(10, same)` / `fo(12, locw)` / `fref` are agreeing arms because
  slang binds their copy-back as a BARE EmptyArgument (or, for `ref`, passes the
  actual straight through) — § outArgLvalue17 already handled them.  They are
  CONTROLS for the mechanism, not tests of it; the tests are the converting rows,
  and the grid varies the actual's width in BOTH directions (narrowing at
  `fo(1, narr)`, widening at `fw(11, locw)`) so that agreement cannot come from
  one accidental type relation.
