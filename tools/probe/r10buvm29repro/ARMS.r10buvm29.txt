* R-STREAMSPAN — the stream operation's own span, 57 SPAN-ONLY cells.
  Surelog gives the stream operation the span of the INNER `{...}` node:
  `fC->populateCoreMembers(Stream_concatenation, Stream_concatenation,
  operation)` (Surelog CompileExpression.cpp:3096).  We compute it as
  (first operand start - 1) .. (last operand end + 1), which coincides with
  the inner braces ONLY when no whitespace separates a brace from an operand
  — true of every bare-stream site in either corpus (`{<<{val}}`,
  `{<< 8 {x, y}}`), false of `{ << bit { __array }}`.  INVISIBLE TO THE JUDGE
  (no generated Compare reads VpiLineNo/VpiColumnNo): g29_f_head PASSES cmp
  with the span still off by one on each end.  Deliberately NOT shipped —
  fixing it would move the bare-stream bytes of 21 corpus databases for zero
  judged effect.
