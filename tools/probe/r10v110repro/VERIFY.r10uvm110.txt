(a1 c18) that it is "PRE-EXISTING on both binaries (the predicate never fires --
our lvalue is already a `ref_obj`, not a `hier_path`)".  The predicate DOES
fire there.  Measured, both views:

  pristine  ref_obj(@@BAD_SYMBOL@@)
  shipped   ref_obj(SHARED)
and the verifier's own v2a_scope.sv c02 `Boxz::STAT2.dyn2 = new [3];` reproduces
it on a different spelling.  It is NOT a regression -- golden has no object, so
neither name matches and the enclosing statement-vector mismatch is identical in
kind on both binaries (a1's shipped cmp head is exactly that `begin` block, and
the pristine database carries the same extra statement).  But the residue text
is wrong and the change is real, so it is corrected in README.md by this
verification.

(STILL on both binaries) -- only the CLASS-scoped static, where slang binds the
`::`-qualified base as a plain NamedValue, reaches the predicate.
