================================================================

The pass's hardest gate asks for the mover set PREDICTED BY NAME, a priori,
before the patched sweep, and for the uhdm2rtlil ZERO to be PROVEN rather than
argued.  A database-side signature cannot do it here: the law's trigger is the
FILE-SCOPE import road as well as the body one, and a file-scope import leaves
NO object in either database (measured — grid arm a8 carries no
`import_typespec` on golden's side or ours).

So the prediction was computed by a THIRD binary whose OBSERVABLE BEHAVIOUR IS
PRISTINE.  It is the patched tree with the new call site wrapped as below; with
`SLANG223_PRED=1` in the environment it DECLINES the mint and only reports, so
the databases it writes are byte-identical to the pristine build's — asserted
per row by `predict223.sh`, which compares each one against the pristine
sweep's own file (surelog 956/956 identical, uhdm2rtlil 1358/1358 identical,
DB-DIFFERING 0 on both).
