## The laws (src/ParamEmit.cpp, each under its own switch; R11U491_OFF drops all seven)

1. § bitNegTypedOperandSize491 (R11U491_BITNEGTYPED_OFF; cases TN, v11u489 VN/vn21, vn27, vn30,
   vn32, vn34 to vn39) — pass 489's first finding. `localparam B = ~A;` with A TYPED: ExprEval's
   vpiBitNegOp masks ~A to the size of the operand constant Surelog holds for A in the instance,
   and that size depends on A's declared type and on how A's value is written (decoded on 109
   Surelog databases, evidence/decode_bitneg_surelog.txt):
   - an instance actual decides alone, whatever A's type: a sized literal its width (4'd5, 4'h5,
     4'b0101, 4'o5 all 4 into logic [7:0]; 12'd5 12), an unsized decimal 64, an unsized based
     'd5, 'h5 or 'b101 -1 (no mask);
   - the default of a SIGNED int or a signed scalar or packed vector (logic signed [3:0] to
     [63:0], signed [7:0], logic signed, a typedef of one): 32 for every literal form;
   - the default of every other kind (integer, integer signed, shortint, byte, longint,
     int unsigned, unsigned vectors, a packed struct, a typedef of one): the literal's width for
     a sized decimal (bit [7:0] A = 4'd4: UINT:11 at size 4; logic [3:0] A = 8'd4: UINT:251 at
     size 8; integer A = 40'd4: size 40), -1 for an unsized 'd4, min(literal width, declared
     width) for a sized binary, the declared width for an unsized decimal, any hex or octal
     literal and an unsized binary; the WRITTEN value is negated and masked (logic [3:0] A =
     8'd20: UINT:235 at size 8);
   - abstains: an enum or a signed packed struct, a signed-class default whose value does not fit
     the declared width (Surelog then negates the truncated value for an unsized decimal and the
     written one for a hex literal: tn101 to tn103).
   Pass 489's typed branch wrote the declared width for every default and abstained on actuals
   other than an unsized decimal.
2. § bitNegUnsizedBasedActual491 (R11U491_BITNEGUNSZACT_OFF; cases TU) — the untyped twin: an
   untyped A overridden by .A('h5) or .A('d5) is held at size -1 (B = UINT:18446744073709551610,
   no mask), where § dpDepBitNegUint489 abstained.
3. § bitNegBareNameActual491 (R11U491_BITNEGBARENAME_OFF; cases NN, r11u489 NB/nb20) — an actual
   that is a bare parameter name .A(P) or .A((P)): the operand is P's own value, sized as P is
   held: an untyped P by how its default is written (unsized decimal 32, sized literal its width,
   unsized based -1, a bare name followed up to eight hops), a typed P with an unsized decimal
   default its declared width (localparam [7:0] P = 5: 8; int P = 5: 32), whatever A's type
   (typed logic [7:0] A with .A(P), P = 5: 32). P overridden, a negative value (nn14, where
   pristine is already right) or a typed P with a sized literal (nn13) abstains.
4. § ovUnsizedBasedActualForm491 (R11U491_OVUNSZFORM_OFF; cases OA, r11u487 BR/br13, br14) — a
   parameter overridden by an UNSIZED based literal keeps the actual's own form in Surelog's
   elaborated param_assign: 'h5 / 'H5 HEX:5 with the decompile 'h5, 'hAb HEX:Ab, 'h1_0 HEX:10,
   'b101 BIN:101 with 'b101, 'o5 UINT:5, 'd5 INT:5, where ours wrote slang's UINT (typed A) or
   INT (untyped A). The size: a typed A keeps ours (the declared width); an untyped A with an
   unsized decimal default 32 (ours -1); an untyped A with a sized default -1. A value wider than
   the declared width keeps the written digits ('hFFF into logic [7:0] HEX:FFF, 'd4095 INT:4095);
   an octal one is masked by Surelog and abstains here when it does not fit. Abstains: an
   untyped A with an unsized based default (ours adds an int typespec golden lacks: tu05, another
   face), a defparam on the parameter, any other actual shape. A continuous assignment reading A
   whole then shares the constant as golden does (oa18, oa19 STRICT_EQUAL).
5. § ovSizedActualMoreBases491 (R11U491_OVSIZEDMORE_OFF; cases OB, v11u489 VO/vo03, vo15) — the
   shapes § ovSizedActualSize489 leaves, an untyped sized-default parameter overridden by a sized
   binary, octal or signed literal: 4'b1010, 4'B1010 and 4'sb1010 BIN:1010 with the decompile
   4'b1010 (underscores dropped), 4'o7 UINT:7, 4'sd3 INT:3 (4'sd9 INT:9, the written digits),
   4'sh3 HEX:3 with 4'h3, an uppercase 4'H3 as 4'h3, each at the literal's size; ours wrote
   slang's INT value (INT:-6 for 4'sb1010) at size -1.
6. § unboundedDepBesideDefparam491 (R11U491_DEPBESIDEDP_OFF; cases UB, v11u489 VU/vu39) — in an
   instance with a defparam, an untyped parameter that reads no defparam'd parameter is valued
   in Surelog's unmasked arithmetic all the same (`B = A + 4'd1` over 4'd15 with `defparam u.X =
   2`: INT:16 where slang wraps to 0) and a later dependent reading both (`C = B + X`) sees it
   (18). § dpDepPreDefparamValue487's walk skipped it and § untypedDepUnboundedValue489 runs only
   where that walk did not. The same rule as the 489 law: ev489u's value kept for the
   dependents, written when it differs from slang's and lies in (-2^31, 2^31), a parameter it
   cannot value poisoning its readers, the size law applied when the value stands (ub07).
7. § unboundedSubSize64_491 (R11U491_SUBSIZE64_OFF; cases SS, v11u489 VS/vs07) — Surelog's
   ExprEval vpiSubOp writes its INT result at size 64 whatever its operands (the add takes the
   larger operand's size), so in the trees § unboundedAddSize489 sizes a - anywhere, or a
   dependent of such a parameter, makes the size 64: `localparam B = A - 4'd1` over 4'd3 is INT:2
   size 64 where the 489 law wrote 4 (visible when B is read as an operand; a whole right side
   shares the constant at the reader's width, which hid it on pass 489's grid).

And the comment fixes (no code token changed): lit487's comment now says what the reader
accepts (an unsized decimal up to 2147483647, a d, h, o or b literal unsized or sized 1 to 64
with a size of at most two digits, its value fitting the width, at most 16 digits once
underscores are removed, so a binary or octal literal of more than 16 digits is not valued), and
the § dpDepPreDefparamValue487 comment quoting it says "unsized or sized 1 to 64, at most 16
digits".
