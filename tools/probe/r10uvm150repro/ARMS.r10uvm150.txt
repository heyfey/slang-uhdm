r10uvm150 — GRID SCORES.  arm150.sh builds each arm with Surelog (golden,
both views) and with the FROZEN pristine / patched binaries; score150.py
extracts each named cell's DUMP SUBTREE from golden / pristine / patched
(object ids and the arm workdir normalised away) and classifies it.
STRICT = raw dump identity.  JUDGE = with VpiParent and VpiFullName
removed, i.e. what uhdm-cmp actually reads (no generated Compare reads
VpiParent; VpiFullName is dump-only).

  FIXED      pristine != golden, patched == golden      (TO-GOLDEN)
  BROKEN     pristine == golden, patched != golden      (AWAY-GOLDEN)
  MOVEDWRONG both wrong and the cell CHANGED
  UNMOVED    both wrong, cell untouched by this pass
  RIGHT      pristine == patched == golden (an agreeing cell is not a
             testing cell — it is counted, never claimed as evidence)
