r10uvm149 -- THE CENSUS.  MEASUREMENT ONLY; the sole acceptance judge is
the official ~/git-repos/UHDM/build/bin/uhdm-cmp.

LHS is ALWAYS golden (Surelog); RHS is ALWAYS ours.

ct149cen emits ONE ROW per typespec_member, keyed
  <owner-kind>|<owner-name>|<member-name>|<line>:<col>
with the DEF/ELAB VIEW deliberately OUT of the key (the two producers
label it differently) and the FILE out of the key as well (our
typespec_members carry an EMPTY VpiFile; a file in the key would make
every cell one-sided and manufacture AWAY phantoms).  The payload is
COMPARE-VISIBLE ONLY: every field typespec_member::Compare,
array_typespec::Compare, range::Compare and constant::Compare (+
expr::Compare's VpiDecompile/VpiSize) actually read, one level down into
the ELEMENT typespec -- typespec::Compare recurses Elem_typespec, so an
element carrying an Instance golden leaves null is a real cmp failure the
top level alone cannot show.  cen149.py joins the two sides as MULTISETS
(keys COLLIDE across views; a last-writer dict would drop rows and a
NODEDUP census would manufacture phantoms).  away149.py scores the three
files together.
