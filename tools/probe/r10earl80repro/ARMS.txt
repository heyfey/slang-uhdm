r10earl80 — THE ARMS, and what each one is FOR.  MEASUREMENT ONLY.

g1_hops80.sv   THE WIDTH AXIS.  288 families, 864 param_assign keys, 1728
               scored cells.  Generated by `GRID80=g1 gengrid80.py`.
               Chain (the head's own shape, module for module):
                 top80 --.A(<S>)--> <n>_h1( <M> A = <S> )
                        --.B(A)---> <n>_h2( int unsigned B = 2 )
                        --.D(B)---> <n>_lf( int unsigned D = 4 )
               so A is hop 0, B hop 1, D hop 2.
               S  12 spellings: 4'h2 8'h2 4'd2 4'b10 4'o2 '0 'h2 2 16'h2 1'b1
                                4'h0 33'h1
               M   8 declared types: bit [3:0] / bit [7:0] / logic [7:0] /
                                int unsigned / int / bit [31:0] / untyped / bit
               HOME 3: DECL (A's own default, no override at the site)
                       OVR  (the literal WRITTEN at the instantiation site —
                             the Earlgrey shape)
                       LP   (a top-level localparam of type <M> passed as the
                             actual — the r10earl27/28 qc28 shape)
               ANSWERS: is the decompile's width the SOURCE literal's, the
               intermediate FORMAL's, or the FINAL formal's — at each hop.

g2_mask80.sv   THE TRUNCATION / SIGN AXIS.  240 families, 720 keys, 1440 cells.
               `GRID80=g2 gengrid80.py`.  Same chain, sources chosen so that
               adjustSize's UINT-mask arm, its logic-BIN truncate arm and its
               int-BIN sign-extend arm would all FIRE if a hop ran them:
                 8'b10110011  8'hff  300  4'sb1000  8'sh80  16'habcd  2
                 1'sb1  8'd200  5'b11111
               ANSWERS: does an intermediate hop MASK / TRUNCATE / SIGN-EXTEND
               the value it carries, or does the raw override Value pass
               through?  This is the arm that proves the law is not a
               decompile-only rule (`.A(300)` into `bit [3:0]` reads golden
               UINT:300 one hop on, UNMASKED).

               THE FOUR SIBLING ARMS THE WIDE BOUNDARY FLAGGED AS MOVERS.

               All eleven moved rows are the SAME shape as the corpus head:
               golden `4'h2`/`4'h0`/`32'hab`, pristine re-rendered at the last
               hop's width, patched == golden.
