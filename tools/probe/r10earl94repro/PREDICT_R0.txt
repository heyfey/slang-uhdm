    WHAT `ln94.cpp` MEASURED (the decode this pass hands over):

    1. OUR OWN DEF-VIEW LISTING IS ALREADY RIGHT.  In `work@prim_lfsr`'s own
       listing we emit `ref_obj LfsrDw` and `ref_obj GAL_XOR_LUT_OFF`
       unbound, exactly as golden does.  Only the ELABORATED copy folds.  The
       producer is therefore the elaborated gen-scope cont_assign RHS path in
       `emitBlock` -- specifically `genCaLhsParamFold`, which
       `src/ModuleEmit.cpp` sets to `!blkInLoop3` for a gen-IF body, and which
       `gen_lut` (an if-generate) turns ON.
    2. GOLDEN FOLDS NOTHING IN THAT WHOLE STATEMENT: `LfsrDw` at 308:38,
       `GAL_XOR_LUT_OFF` at 308:45 and `LfsrDw` at 308:62 are ALL symbolic on
       the golden side, while we emit UINT:64 / UINT:4 / UINT:64.
    3. YET GOLDEN DOES FOLD ELSEWHERE IN THE SAME GEN SCOPE: four lines down,
       at 315:53-315:59, the replication count `{LfsrDw{...}}` is
       `constant UINT:64 vpiSize 32` on BOTH sides.  So the distinguisher is
       NOT "a gen scope suppresses folding"; it is THIS EXPRESSION.
    4. THE CANDIDATE DISTINGUISHER, to be isolated by the next pass:
       `GAL_XOR_COEFFS` is a localparam UNPACKED ARRAY of 168-bit values, and
       the whole `var_select` is un-evaluable by Surelog's ExprEval -- so
       `reduceExpr` bails on the SELECT and the UNREDUCED index tree survives,
       index and all.  An arm row measured here says the opposite case folds:
       `m_net[W-KOFF]` on a NET produces NO ref at all on either side (both
       fold), so the bail is a property of the SELECTED OBJECT, not of the
       index.  Purpose-built goldens must cross: selected object (net /
       variable / packed localparam / UNPACKED localparam array / wide
       (>64 bit) element) x select kind (bit_select / part_select /
       var_select) x gen-scope kind, and the un-evaluability must be measured,
       not assumed.
    5. THE SECOND HALF IS A BINDING, and it is THIS PASS'S mechanism again:
       once the ref survives, the ELABORATED copy must carry
       `Actual_group -> parameter LfsrDw` of the instance while the DEF copy
       carries <null> -- which is `UhdmWriter::lateBinding`'s parameter arm,
       run per written scope.  Decide the fold and the binding together.
